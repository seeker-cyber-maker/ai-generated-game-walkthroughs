-------------------------------------------------------------------------------
[03.01] FILE SYSTEM HIERARCHY (/sys/, /bin/, /log/, /home/)             [ARC01]
-------------------------------------------------------------------------------

• /sys/: Core OS daemons. Crucially houses x-server.sys (which renders the
  graphical GUI) and os-config.sys. Deleting x-server.sys crashes GUI to CLI!
• /bin/: Executable binaries and port cracking utilities (PortHack.exe, etc.).
• /log/: Connection logs and file access journals. Admin traces track your home
  gateway IP unless all logs are sanitized with `rm *` before disconnecting!
• /home/: User directories, mission contracts, emails, and corporate databases.

-------------------------------------------------------------------------------
[03.02] RAM MANAGEMENT & PROCESS CONCURRENCY                            [ARC02]
-------------------------------------------------------------------------------

Your gateway has a fixed RAM limit (starts at 300 MB, upgradeable to 600+ MB).
Tools consume dedicated blocks:
  • PortHack.exe: 200 MB
  • FTPBounce.exe: 150 MB
  • SSHcrack.exe: 180 MB
  • SMTPoverflow.exe: 160 MB
  • WebServerWorm.exe: 190 MB
  • SQL_MemCorrupt.exe: 210 MB

-------------------------------------------------------------------------------
[03.03] DEFENSIVE MEASURES: PROXIES, FIREWALLS & DECYPHERS              [ARC03]
-------------------------------------------------------------------------------

1. PROXY NODES:
   Run `analyze` to track shifting hex offsets; type `solve <hash>` repeatedly
   until proxy overload reaches 100%.
2. FIREWALLS:
   Type `analyze` to identify the bypass cipher, then type `solve <pass>`.
3. ENCRYPTED FILES (.dec):
   Run `DECHead <file.dec>` to inspect the header key; run `Decypher <file.dec>
   <key>` to reveal plaintext data.
