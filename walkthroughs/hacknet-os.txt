-------------------------------------------------------------------------------
[03.01] FILE SYSTEM HIERARCHY (/sys/, /bin/, /log/)                     [ARC01]
-------------------------------------------------------------------------------

Every node runs a standardized UNIX-like file hierarchy:
• /sys/: Core OS daemons. Houses x-server.sys (renders graphical GUI) and
  os-config.sys. Deleting x-server.sys crashes GUI to raw CLI mode.
• /bin/: Executable binaries and port cracking utilities (PortHack.exe, etc.).
• /log/: Connection logs and file access journals. Admin traces track your home
  gateway IP unless all logs are sanitized with `rm *` before disconnecting!
• /home/: User directories, mission contracts, emails, and corporate databases.

[SOURCE PROOF: HackerScripts/ThemeHack.txt:8-9]
  8: delete /sys x-server.sys $#%#$
  9: forkbomb $#%#$
(Proves GUI relies entirely on /sys/x-server.sys).
