[07.00] HISTORICAL COPY-PROTECTION: DIAL-A-PIRATE DRM & CRACKS          [PROT]
===============================================================================

A. THE DIAL-A-PIRATE CODE WHEEL:
  In 1990, LucasArts included a double-sided cardboard code wheel. Players had
  to align pirate face halves with island ports to enter a 4-digit hanging
  year.

B. REVERSE-ENGINEERED SCUMM SCRIPT CRACK:
  In SCUMM script room-16 (DISK01.LEC), the VM compares entered year digits.
  Early crackers NOPed the mismatch conditional jump, allowing any input code
  to bypass protection.
