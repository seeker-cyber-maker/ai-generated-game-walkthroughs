  • Ammon (House Ordos): Sigma Draconis technocrat. Cold and calculating;
    views warfare as a mercenary balance sheet transaction.

C. THE GRAND BETRAYAL:

  Imperial Sardaukar legions alongside both rival Houses in a 3-against-1 war.

[04.00] THE BIRTH OF THE RTS AI: HISTORICAL CONTEXT                     [HIST]
===============================================================================

Released in 1992 by Westwood Studios, Dune II defined the modern Real-Time
Strategy (RTS) genre. Running on a 16MHz Intel 286/386 with under 640 KB of
DOS memory, the AI could not use modern neural nets or deep search trees.
Westwood built an ultra-efficient suite of Finite State Machines (FSMs) and
heuristic weight tables that simulated a live opponent in real time.

[05.03] WAVE ASSEMBLY & STAGING TRIGGER FSM (ai.c)                      [ARC03]
-------------------------------------------------------------------------------

The AI pools manufactured units at a staging point until threshold is met:

/* Reverse-Engineered C Routine: ai.c */
void AI_ProcessUnitState(Unit *u) {
    if (u->houseID == g_humanHouseID) return;
    switch (u->actionState) {
        case ACTION_IDLE:
            if (u->groupPoolID != GROUP_NONE) {
                TileCoord rally = g_scenario.aiRallyPoint[u->houseID];
                Unit_SetDestination(u, rally);
                u->actionState = ACTION_STAGING;
            }
            break;
        case ACTION_STAGING:
            if (Tile_Distance(u->currentTile,
                g_scenario.aiRallyPoint[u->houseID]) <= 2) {
                g_scenario.stagedUnitCount[u->houseID]++;
                u->actionState = ACTION_WAITING_FOR_WAVE;
                if (g_scenario.stagedUnitCount[u->houseID] >=
                    g_scenario.waveThreshold[u->houseID]) {
                    AI_LaunchAttackWave(u->houseID);
                }
            }
            break;
    }
}

void Devastator_ReactorMeltdown(Unit *u) {
    for (int dx = -3; dx <= 3; dx++) {
        for (int dy = -3; dy <= 3; dy++) {
            TileCoord blastTile = { u->currentTile.x + dx,
                                    u->currentTile.y + dy };
            int dist = Tile_Distance(u->currentTile, blastTile);
            if (dist <= 3) {
                int dmg = 500 / (dist + 1);
                Tile_ApplyRadialDamage(blastTile, dmg);
            }
        }
    }
    SpawnNuclearMushroomCloud(u->currentTile);
}

/* Reverse-Engineered C Routine: sandworm.c */
void Sandworm_ExecuteMawStrike(Sandworm *w, TileCoord targetTile) {
    Unit *victim = g_map[targetTile.x][targetTile.y].occupantUnit;
    if (victim != NULL) {
        Unit_DestroyInstantly(victim);
        PlaySound(VOCAB_WORM_DEVOUR);

A. PROVENANCE & THE 27 CUSTOM SCENARIOS:
  Created in 1993-1994 by Stefan Hendriks and Gerben van Kesteren, Super Dune
  II was an unofficial community total conversion distributed via BBS networks
  and shareware disks. It replaced the campaign with 27 brand-new, hardcore
  missions across 3 previously engine-restricted playable factions:

  1. House Fremen (Desert Indigenous Campaign - 9 Missions):
     • Natural desert camouflage infantry spawn without Palace prerequisite.
     • Sonic Tanks unlocked early at Tech Level 5.
  2. The Mercenary Guild (Scavenger Campaign - 9 Missions):
     • Hybrid unit roster: can produce Ordos Raider Trikes and Harkonnen
       Missile Tanks simultaneously at discounted credit costs.
  3. The Imperial Sardaukar (Dreadnought Legion - 9 Missions):
     • Standard infantry replaced by elite Heavy Rocket Sardaukar.
     • Devastators / Obliterators unlocked early in Scenarios 4-5.

B. THE DEVASTATOR / "OBLITERATOR" / "ANNIHILATOR" SELF-DESTRUCT:
  In European shareware and Russian/Ukrainian bootlegs, the Devastator was
  frequently translated as the "Obliterator" or "Annihilator":

  • Dedicated UI Button: Selecting the Obliterator reveals a manual
    "Self-Destruct" command button on the interface (Hotkey: 'D').
  • Last-Resort Kamikaze Blast: A 1.5-second siren triggers before the unit
    detonates in a thermonuclear mushroom cloud, dealing 500 radial splash
    damage across 3 tiles to obliterate surrounding enemy armor and bases.
  • Tactical Role: Driving a damaged Obliterator into an enemy refinery
    cluster or turret line and detonating it is the premier speedrun tactic.

C. EXTREME DIFFICULTY AI TUNING:
  • AttackWaveRate doubled: AI wave delay timers slashed from 300 to 120 ticks.
  • AI starting credit reserves boosted to 9,999 credits.
  • Concurrent multi-factory build orders resulting in crushing armor rushes.
